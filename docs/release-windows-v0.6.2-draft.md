# Deadline Panel v0.6.2 for Windows

- 同步 macOS 0.6.2 的主要功能更新：完善任务编辑、历史记录与恢复、延期菜单等操作，加入低功耗模式。
- 全面重做 Windows UI：重新设计悬浮面板、胶囊控件和“设置与工具”界面，整理任务操作布局，并适配 Windows 风格的窗口按钮。
- 更新深浅色外观：默认使用深色模式，采用圆角半透明背景，提升浅色模式的文字与边界对比，修复空任务时面板与收起条之间的空缺。
- 优化任务录入与数据管理：强化自然语言日期、时间识别，加强云同步冲突保护和删除重试，完善 JSON 导入导出与数据库备份，修复重启及悬浮窗隐藏后的恢复。
