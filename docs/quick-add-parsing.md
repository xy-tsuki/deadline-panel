# 自然语言快速添加规则

快速添加在本地运行，不调用 AI，也不上传解析输入。点击“解析”或回车先生成预览，确认添加后才保存任务；任务保存后遵循已有云同步设置。

## 支持的写法

| 类型 | 示例 |
| --- | --- |
| 中文日期 | `10月12日`、`十月十二号`、`2026年10月12日`、`明年1月2日` |
| 数字日期 | `2026-10-12`、`2026/10/12`、`2026.10.12`、`10/12`；支持全角数字 |
| 相对日期 | `今天`、`明天`、`后天`、`大后天`、`三天后`、`两个星期后` |
| 星期 | `周五`、`本周五`、`下周五`、`下个星期五`、`下下周一`、`这个周末` |
| 月内日期 | `15号`、`下个月十五号`、`本月底`、`下月底` |
| 时分 | `18:30`、`下午三点`、`晚上八点半`、`三点一刻`、`三点四十五分` |
| 从现在起计时 | `两小时后`、`半小时后`、`一个半小时后`、`1小时30分钟后`、`30分钟后` |
| 英文与日文 | `tomorrow at 3:30pm`、`next Friday`、`in three days`、`Oct 12, 2026`、`明日午後三時半`、`来週金曜日`、`3日後` |
| 优先级 | `高优先级`、`优先级：高`、`最高优先级`、独立的 `重要` / `不急`，以及 `urgent/high/medium/low`、`P0/P1/P2/P3` |
| 备注 | 末尾加 `，备注：内容`、`; notes: text` 或 ` メモ：内容`；备注中的日期不会参与截止时间解析 |

例如 `下周五下午三点半之前提交报告 高优先级，备注：附上本周实验结果` 会生成标题“提交报告”、下周五 15:30、high 优先级及对应备注。

## 日期和时间约定

- 按本机时区解释日期和时间，保存时转换为 ISO 时间戳。
- 自然周从周一开始。“下周五”取下一自然周的周五，不取最近的周五；“周末”取周日 23:59。
- 未写“本周/下周”的星期取下一次尚未经过的对应时刻。当日截止时间还没到，就取今天；已过则取下一周。
- 月日未写年份时取当前年；若该截止时刻已过，取下一年。单独“15号”取当月，已过则取下月；明确“今年/本月”的写法允许过去日期。
- 只有日期，默认 23:59。“今晚”或“晚上”没有具体钟点时也使用 23:59；“上午/下午”缺少具体钟点会提示补充时间。
- 只写具体钟点时，取下一次该时刻：今天尚未经过则取今天，否则取明天。
- `24:00`、`晚上十二点` 表示所选日期结束后的零点；`凌晨十二点` / `12am` 表示日期开始的零点。
- 未指定优先级时为 medium。识别到多个优先级标记时取最高级别；中文词嵌在“重要性分析”“普通话考试”这样的标题里时保留原文。

## 需要人工核对的情况

- 一次解析一条任务。多个不同日期或钟点、无效日历日期、无效时分和夏令时不存在的本地时刻会被拒绝，不静默选一个值。
- 支持固定写法，不能理解任意自然语言。“下周”“近期”“过几天”等没有确定日期的表达需补全；日期范围和多个任务请分条填写。
- 快速添加不解释时区偏移或已识别的 UTC/JST 等时间标记。这类时间通过带明确时区的命令或 JSON 导入。
- 无年份的闰日若在推断年份中不存在，需写明有效年份；不会猜测多年后的闰日。
- 任务名称本身包含日期或时间时仍可能有歧义，应核对预览，或使用手动填写。
