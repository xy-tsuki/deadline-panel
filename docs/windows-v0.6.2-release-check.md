# Windows 0.6.2 发布前复核（2026-10-08）

当前结论：功能回归、生产构建和更新签名检查通过，已生成 Windows x64 发布候选。正式安装/覆盖升级、通知投递、跨设备云同步和桌面拖动验收仍待完成，不能据此宣称完整发布验收通过。

## 本次确定的界面基线

- Windows 10 圆角半透明界面，关闭模糊、背景采样及应用材质渲染线程。
- 默认深色；已保存的浅色或跟随系统设置继续生效。
- 深色收起条不透明度 80%，展开面板 85%，设置窗口 95%。浅色背景 96%，使用更深的文字和灰蓝边界。
- 空任务显示“暂无 Deadline”；向上展开时，短面板内容贴底补齐与收起条之间的空缺。向下展开时内容贴顶。
- 设置窗口按屏幕工作区一次确定尺寸，禁止用户调整大小和最大化；保留右侧最小化、关闭按钮，最大化按钮禁用。深浅色主题统一无滚动条；小屏使用紧凑布局，必要时缩放内容以显示完整设置。
- 开机启动改用 Windows 注册表 API 直接读写，移除 `reg.exe` 子进程。独立应用标识使用独立启动项，测试后清理。
- 延期按钮独立放在任务行右侧，其余三个任务操作按钮放在左侧。

## 环境与隔离方式

- 实测系统：Windows 10 Home China 22H2，内部版本 19045，x64。
- 生产候选使用原应用标识 `local.adhd-deadline-panel`，版本号 0.6.2。
- 原生功能验收使用相同源码、相同生产前端和 release 优化配置，仅将应用标识改为 `local.adhd-deadline-panel.acceptance-062`。其 SQLite 数据、单实例与 WebView 环境独立，未操作用户正式数据库。
- 该隔离验收不是对安装包安装过程或正式应用标识下通知投递的替代。
- 测试程序中的任务为合成测试数据；原有用户测试程序保持运行。
