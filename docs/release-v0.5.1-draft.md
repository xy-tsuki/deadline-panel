# Deadline Panel v0.5.1 Release 草稿

## 更新内容

- 将悬浮面板改为双窗口架构：收起条和展开面板分别使用独立窗口。
- 修复未展开时透明展开区域遮挡后方窗口的问题。
- 优化展开面板向上 / 向下展开的定位逻辑，展开面板会贴近收起条显示。
- 当屏幕边缘空间不足时，展开面板会自动缩短高度，避免远离收起条或与收起条重合。
- 拖动逻辑改为只允许拖动收起条，展开面板不再参与拖动。
- 修复收起条 hover 时文字可能闪烁的问题。
- 收起条鼠标样式改为普通箭头。
- 无当前任务时，展开面板顶部标题改为“最近截止”，与收起条语义保持一致。
- 展开面板最大高度从 642px 调整为 600px，降低视觉占用。

## 测试建议

- 将收起条拖到右上、右下、屏幕中部等不同位置，确认展开面板贴近收起条。
- 分别测试向上展开和向下展开，确认没有闪烁、跳动或重合。
- 长时间闲置后再移动鼠标到收起条，确认可以正常展开。
- 鼠标移到收起条、展开面板、输入法悬浮窗附近，确认不会异常收起或误触发。
- 测试任务新增、修改、完成、延期、导入、同步、历史记录等主流程。
