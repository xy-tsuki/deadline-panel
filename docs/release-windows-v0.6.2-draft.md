# Deadline Panel v0.6.2 for Windows

- 更新悬浮面板和设置界面：默认使用深色模式，优化浅色模式在白底上的可读性；采用圆角半透明背景，深色悬浮面板不透明度为 80%，设置窗口使用右侧 Windows 风格窗口按钮。修复空任务时面板与收起条之间的空缺，以及设置窗口打开时卡死的问题。
- 完善任务操作：支持标题、截止时间、备注和优先级编辑，历史任务可编辑并恢复；当前任务按钮与完成、删除按钮放在左侧，延期菜单独立放在右侧。Top 3 / 5 / 10 支持点击、拖选和键盘切换。
- 加强云同步稳定性：完善请求超时、删除重试、墓碑过滤和冲突保护，减少旧数据覆盖新修改或已删除任务重新出现的问题。
- 改进数据导入与备份：JSON 导入逐项校验日期、状态和优先级，保留有效时间戳并处理重复 ID；批量写入失败时整体回滚，数据库备份包含已提交但尚未合并到主文件的数据。
